# ICOPE 共學・系統討論：暖暖衛生所

115 年度長者內在能力檢測服務共學活動「系統討論」網頁簡報。以暖暖衛生所 2026/01–08 去識別化服務數據（646 位長者）為例，看流程亮點與優化點，再請各單位反思自己。

線上版：https://mattsue1003.github.io/icope-system-nuannuan/

## 操作
- ← → 或空白鍵換頁，`T` 目錄，`N` 講者備註，`F` 全螢幕；網址加 `#s9` 直接開第 9 頁
- 手機自動切換成上下捲動
- 第 22 頁自我診斷計算器、第 25 頁行動承諾卡（只存在本機瀏覽器）

## 檔案
- `index.html`：GitHub Pages 用（`zsh assemble.sh` 產生）
- `parts/`：簡報內容（slides.html、extra.css、calc.js）
- `ppt_build.py`：產生可列印 PPT（`python3 ppt_build.py`）
